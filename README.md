# Cipher Diary

Cipher Diary is a C-based diary application that allows users to securely manage personal diary entries through a simple command-line interface.

## Features

- User registration and login
- Password-protected access
- Create diary entries
- View diary entries
- File handling using C
- Simple command-line interface

## Technologies Used

- C Programming
- File Handling
- Encryption/Cipher Concepts
- Data Structures

## How to Run

Compile the program using GCC:

```bash
gcc cipher_diary_v2.c -o cipher_diary_v2
